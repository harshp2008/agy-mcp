# agy-mcp codebase map and job flow

Status: current
Audience: contributors, maintainers

This document tells a new AI or human where things live in `agy-mcp`, what each
module owns, and where to look when something goes wrong. Hand-written
prose is maintained by humans. The module table at the bottom is regenerated by
`scripts/gen_codemap_index.py` and is checked by `tests/test_codemap_fresh.py`.

Keep it fresh:

```bash
.venv/bin/python scripts/gen_codemap_index.py --write
.venv/bin/python scripts/gen_codemap_index.py --check
.venv/bin/python -m pytest tests/test_codemap_fresh.py -q
```

## How a job flows (agy_start through finalization)

The numbered calls below are the real path through the code. The orchestrator
(the AI client) drives steps 1 and 7-9 through MCP tools; steps 2-6 happen in
worker threads.

1. **`server.agy_start()`** (`server.py`) runs the synchronous body in
   `anyio.to_thread.run_sync` and calls **`JobManager.start()`** (`manager.py`).
2. **`JobManager.start()`** validates:
   - `prompt` non-empty and ≤ `MAX_PROMPT_BYTES` (100,000),
   - `max_minutes` ≤ `config.max_minutes_cap`,
   - `model` ∈ `config.model_allowlist`,
   - `verify` through **`verify.is_verify_allowed()`**,
   - repository through **`worktree.validate_repo_path()`** (containment, `.git`
     directory, resolvable HEAD, `.agents/**` trust gate),
   - free disk (`shutil.disk_usage`) and total state-disk budget,
   - the usage guard through **`JobManager._apply_usage_guard()`** →
     **`usage.get_usage()`**; with a registry, **`accounts.selection.AccountSelector.select()`**
     validates each account home and policy, reads that account's `/usage`, and
     calls the pure **`accounts.scheduler.schedule_account()`** (D102–D109).
   It then enters **`jobs.concurrency_lock()`**, calls
   **`jobs.count_active_jobs()`**, **`jobs.check_and_increment_daily_cap()`**
   and **`jobs.create_job()`** (which writes `prompt.txt`, `job.json` and the
   `job_created` audit event), and starts the `_provision_and_launch` thread.
   It returns a `StandardEnvelope` in state `queued`.
3. **`JobManager._provision_and_launch()`** (`manager.py`) calls
   **`worktree.create_worktree()`** (`git worktree add -b agy/<slug>-<id>`),
   then **`worktree.provision_metadata_dir()`** (0700 `.agy/`, four seeded
   scratchpad files via `scratchpad.seed_scratchpad`, repository-local
   `info/exclude`; A4/D62), builds the full prompt with
   **`util.format_fresh_prompt()`** (preamble + task), builds argv with
   **`runner.build_argv()`**, takes a fresh launch usage reading, and calls
   **`runner.LocalProcessRunner.launch()`** (new session/process group,
   file-backed stdout/stderr).
   It writes `pid`, `pgid`, `start_time`, `stdout_offset`, `launch_wall_clock`,
   transitions `queued → running` with **`jobs.transition_job_state()`**, takes
   **`audit.take_snapshot()`** and **`audit.save_snapshot()`**, constructs
   **`supervisor.JobSupervisor`**, and starts the `_run_supervisor` thread.
4. **`JobSupervisor.run_loop()`** (`supervisor.py`) calls
   **`JobSupervisor.tick()`** about every second. `tick()`:
   - checks the wall-clock deadline (`min(max_minutes, max_minutes_cap) * 60 +
     120` seconds) and checkpoints/kills on expiry,
   - runs **`audit.audit()`** every 5 seconds and processes findings with
     **`JobSupervisor._process_audit_findings()`**,
   - calls **`watcher.CommitWatcher.tick()`**, which validates and consumes
     `.agy/COMMIT_MSG`, stages with **`gitops.stage_changes()`**, and commits
     with **`gitops.commit_with_retry()`**,
   - polls the process with **`runner.LocalProcessRunner.poll()`**.
5. On process exit, **`JobSupervisor._finalize_terminated_process()`**:
   - reads capped stdout/stderr tails and the `cli.log` tail
     (**`cli_log.read_cli_log_tail()`**),
   - extracts soft denials with **`cli_log.extract_denials_from_cli_log()`**,
   - classifies the outcome with **`parse_result.parse_agy_output()`**,
   - takes a fresh final usage reading and computes cost with
     **`usage.compute_usage_cost()`**,
   - runs the post-completion **`audit.audit()`**,
   - optionally runs **`verify.run_verify()`** and audits again,
   - creates a safety-net commit with **`gitops.safety_net_commit()`**,
   - enriches denials with **`transcript.read_denied_calls()`**,
   - accounts for `.agy/PLAN.md` via **`scratchpad.read_plan()`** (warning and
     `needs_review(plan_incomplete)` when items remain; D62),
   - captures `.agy/REPORT.md` via **`scratchpad.read_scratchpad_file()`** into
     `agent_report` and adds `report_claims_unverified` when it claims tests
     passed but verify did not (D62),
   - records cumulative time with **`jobs.record_job_execution_time()`**,
     appends the usage row with **`usage.record_usage()`** (before the state
     becomes observable, D68/D77), transitions the job with
     **`jobs.transition_job_state()`**, and cleans up the process with
     **`runner.LocalProcessRunner.cleanup()`**. The watcher, tick-failure and
     crash-recovery paths use the same ordering through
     **`JobSupervisor._record_usage_before_state()`** and
     `CommitWatcher(before_state_transition=...)`.
6. **`JobManager._run_supervisor()`** runs after the loop: it retains the
   scratchpad with **`scratchpad.copy_to_jobdir()`** and may auto-resume:
   **`JobManager._handle_verification_auto_fix()`** for verify failures,
   **`JobManager._handle_denial_auto_resume()`** for permission denials with
   zero commits, or **`JobManager._handle_plan_nudge()`** once for unticked plan
   items. All call **`JobManager.resume()`**, which prepends the
   **`scratchpad.format_state_block()`** state-of-the-world block.
7. **`server.agy_wait()`** → **`JobManager.wait()`** polls `job.json` until the
   state leaves `queued`/`running` (max 300 s per call).
8. **`server.agy_status()`** → **`JobManager.status()`** builds a
   `JobStatusResponse` and adds liveness from
   **`recovery.get_liveness_summary()`** (`cli.log` mtime, last commit, dirty
   state, redacted log tail).
9. **`server.agy_result()`** → **`JobManager.result()`** reads stdout, diff
   stat, commits and audit tail; **`server.agy_review()`** →
   **`JobManager.review()`** computes merge base/ahead/behind, `base_moved`,
   audit findings and the capped untrusted diff; **`server.agy_cleanup()`** →
   **`JobManager.cleanup()`** → **`worktree.cleanup_worktree()`**.

Resume path: **`server.agy_resume()`** → **`JobManager.resume()`** first joins
any previous run's supervisor thread so its final job-record write cannot race
the new generation (D65), then checks the state gate, cumulative budget, usage
guard, the persisted `snapshot.json` audit gate, and re-validates `verify`; it
builds the state block with **`JobManager._build_state_block()`** →
**`scratchpad.format_state_block()`**, assembles the prompt with
**`util.format_resume_prompt()`** (preamble once, state block, wrapped
answer/guidance), builds argv with
`runner.build_argv(..., conversation_id=...)`, launches, and
transitions `needs_decision|timeout|needs_review(non-security) → running`.

Startup path: **`server.setup_server()`** → **`JobManager.reconcile()`** →
**`recovery.reconcile_on_startup()`** reattaches living processes or finalizes
dead ones; **`jobs.cleanup_retained_jobs()`** prunes old terminal job dirs.

## Where do I look when…

| Symptom / question | Look at | Why |
| --- | --- | --- |
| A job is stuck in `queued` | `manager.JobManager._provision_and_launch`, `worktree.create_worktree`, `job.json`, `server.log` | Provisioning failures are written as `FAILED/review_reason=setup_failed`; check the worktree-add timeout and the job's `error`. |
| A job is stuck in `running` | `supervisor.JobSupervisor.tick`, `job.json` (`pid`, `pgid`, `start_time`), `<jobdir>/cli.log`, `recovery.get_liveness_summary` | `tick()` owns the deadline, process poll, watcher and audit timers; `agy_status` surfaces cli.log mtime/last commit/dirty state. |
| The audit says a violation | `audit.audit`, `audit.check_host_path_snapshot`, `supervisor._process_audit_findings`, `jobs.transition_job_state` | Fatal findings become `needs_review` with reasons `audit_violation`, `host_path_modified`, `instruction_file_modified`, `audit_unavailable`. |
| A commit did not happen | `watcher.CommitWatcher.tick`, `_process_settled_commit_msg`, `gitops.stage_changes`, `gitops.commit_with_retry` | Checks the 5 s settle window, message validation, audit gate, sensitive/junk filters and `index.lock` retries. |
| A job will not resume | `manager.JobManager.resume`, `jobs.transition_job_state`, `audit.load_snapshot` | Resume is blocked for terminal security reasons, exhausted budget, missing snapshot, fatal audit, or disallowed verify. |
| Verify looks wrong | `verify.is_verify_allowed`, `verify.run_verify`, `supervisor._finalize_terminated_process` (verify block), `manager._handle_verification_auto_fix` | Allowlist/flag/path rules live in `verify.py`; the supervisor stores `verify_status` and `verify_tail.txt`. |
| Usage or quota looks wrong | `usage.parse_usage_payload`, `usage.read_usage_once`, `usage.get_usage`, `manager._apply_usage_guard`, `usage.compute_usage_cost` | Parsing, 60 s cache, guard modes and per-job cost all live in `usage.py`; `usage.jsonl` is the append-only record. |
| A denied command is missing | `cli_log.extract_denials_from_cli_log`, `transcript.read_denied_calls`, `supervisor` denial block | `cli.log` only has step numbers; the command text comes from the confined transcript reader. |
| I need to add a config key | `config.Config`, `config._validate_config_dict`, `doc/design/spec.md` §18, this file | Add the dataclass field, add it to `known_keys`, add validation, document it in SPEC §18 and code layout. |
| I need to add a tool parameter | the tool in `server.py`, the matching `manager.JobManager` method, `doc/design/spec.md` §8, this file | Tool signature, manager method signature, envelope docs and SPEC must move together. |
| The state machine does not allow something | `states.TRANSITION_TABLE`, `jobs.transition_job_state` | The table is the authority; `transition_job_state` rejects unknown edges. |
| Cleanup refuses to delete a branch | `worktree.cleanup_worktree`, `worktree.count_unmerged_commits`, `manager.JobManager.cleanup` | Dirty-worktree gate and the reachability gate (HEAD or any other local branch) require `force=True`; squash/cherry-pick merges stay unmerged (D70). |
| Next actions in an envelope look wrong | `models.derive_next_actions`, `models.build_standard_envelope` | All `next_actions` text is produced there from state, reason, denials and verify status. |
| Plan, report, or scratchpad looks wrong | `scratchpad.read_scratchpad_file`, `scratchpad.parse_plan_text`, `supervisor._read_plan_summary`, `supervisor._capture_agent_report`, `manager._retain_scratchpad` | All `.agy` reads are no-follow and capped (SPEC §9 security rule); plan/report fields and retained `scratchpad/` copies are built here (D62). |
| Historical pytest fixture rows accumulate in a store | `cleanup_fixtures.py`, SPEC §22, `doc/design/decisions.md` (D87, D88) | Run `python -m agy_mcp.cleanup_fixtures --store <PATH> [--yes]`; dry-run by default, deletes only strict fixture signatures. |
| Stale job records accumulate for a project or explicit job IDs | `cleanup_jobs.py`, SPEC §23, `doc/design/decisions.md` (D89, D90, D91, D92, D93, D94) | Run `python -m agy_mcp.cleanup_jobs --store <PATH> [--list | --project <PATH> | --job <ID>] [--yes]`; dry-run by default, cleans job directories while preserving repos, branches and worktrees. |
| Installing on a new machine or another MCP client | `installer/install.sh`, `installer/agents_block.md`, `doc/project/orchestrator-workflow.md`, `tests/test_installer_chapter.py` | The installer is a bash distribution artifact, not imported by the server; its tests drive it under a temporary HOME. |

## Installer and orchestration (outside `src/`)

These files are not server modules; the generated index below does not cover
them (it only scans `src/agy_mcp/*.py`).

- **`installer/install.sh`** — standalone and sourceable bash installer
  (D67). One command installs the venv/package, config, state dir and run
  files. It has three layers: core (`agy_mcp_install_core`), generic client
  (`agy_mcp_write_generic_files`; a standard `mcpServers` JSON snippet plus
  `orchestrator-guidance.md`, both printed, and the default) and dsh
  (`ch_agymcp`: the `# >>> ai-stack agymcp >>>` block in
  `~/.dsh/profiles/web/cordis.patch.yml` with `toolCallTimeoutMs: 360000` and
  the `<!-- >>> ai-stack agymcp >>> -->` block in `~/.dsh/AGENTS.md`).
  Also provides `doctor_agymcp`, `uninstall_agymcp`, `--dry-run` and
  `refuse_inside_dsh`. Sourceable: when sourced it only defines functions.
  Network fetching is deliberately not implemented (comments only).
- **`installer/agents_block.md`** — canonical orchestrator guidance text; the
  installer embeds the same text and writes it into the dsh AGENTS block and
  the generic `orchestrator-guidance.md` (tests pin the byte equality).
- **`tests/test_installer_chapter.py`** — subprocess tests for the installer:
  temporary HOME, fake `agy`, stub `systemctl`, offline wheel, temp-HOME paths
  only; never touches the real `~/.dsh`.
- **`docs/ORCHESTRATION.md`** — dsh approval caveats (mostly UNSURE from repo
  files), unattended-run checklist, expected quota cost, and the non-dsh
  paste-in procedure.
- **`docs/reports/installer-agymcp/`** — baseline, failing/passing, mutation and
  final evidence for this chapter.

## Module reference

### `__init__.py`
- **Purpose:** package marker; exports `__version__ = "0.1.0.dev0"`.
- **Public API:** none.
- **Imports from `agy_mcp`:** none.
- **Called by:** every import of `agy_mcp`; `server.py` reads `__version__`.
- **Tests:** exercised indirectly by every suite; no dedicated test.
- **Implements:** packaging metadata only (no SPEC section).

### `__main__.py`
- **Purpose:** `python -m agy_mcp` entrypoint.
- **Public API:** none.
- **Imports from `agy_mcp`:** `server.main`.
- **Called by:** `tests/server/test_server_e2e.py` spawns `python -m agy_mcp`.
- **Tests:** `tests/server/test_server_e2e.py`.
- **Implements:** packaging/runtime entrypoint (no SPEC section).

### `accounts/` (package)
- **Purpose:** multi-account foundation: parse/validate `[[accounts]]` from
  `config.toml`, build the implicit `default` account, mask and verify account
  emails, and build each account's sanitized child environment (D102–D104).
- **Modules:**
  - `registry.py` — `AccountConfig`, `AccountRegistry`, `parse_accounts()`,
    `build_registry()`, `validate_account_home()`; reserves the `default` name,
    enforces `1 + len(accounts) <= max_accounts`, and never touches the
    filesystem during config load.
  - `identity.py` — `mask_email(head=3, tail=2)`, `email_sha256()`,
    `IdentityCheck`, `verify_identity()`; the full address stays in memory and
    every error carries the masked form only.
  - `env.py` — `build_account_env()`; adds
    `DBUS_SESSION_BUS_ADDRESS=unix:path=/dev/null` for non-default accounts and
    leaves the default account's env byte-identical to `util.env_allowlist()`.
  - `pools.py` — `WindowReading`, `PoolReading`, `AccountUsage` and
    `account_usage_from_reading()`; the typed view of both pools and windows.
  - `scheduler.py` — `estimate_cost()`, `schedule_account()`,
    `account_eligibility()` and `remaining_until_reset()`; the pure,
    clock-injected cost/filter/ranking/burn decision (D108, D109).
  - `scheduler_types.py` — the immutable scheduler inputs/outputs
    (`SchedulerConfig`, `AccountState`, `JobRequest`, `CostEstimate`,
    `SchedulerResult`) and their UTC helpers.
  - `policy.py` — read-only permission-policy parity between an account home and
    the primary (D106).
  - `selection.py` — `AccountSelector`, `Selection`, `RejectedAccount`; the I/O
    glue that validates homes, reads `/usage`, counts jobs/reservations and calls
    the scheduler (D102–D109).
  - `transfer.py` — the per-conversation lock, SQLite header/WAL checks and the
    atomic db copy between account stores (D111).
  - `handoff.py` — the capped, fenced summary prompt used when the db cannot
    move (D111).
  - `doctor.py` — the read-only account checks behind `installer/install.sh
    --doctor` (D113).
  - `errors.py` — `AccountError` with a stable `.code`.
- **Imports from `agy_mcp`:** `config.py` imports the registry; `env.py` imports
  `util.env_allowlist`; `identity.py` imports only `errors`.
- **Called by:** `config.py` (parsing); later phases consume the registry,
  identity and env from the manager, scheduler and doctor.
- **Tests:** `tests/test_accounts_registry.py`,
  `tests/test_accounts_identity.py`, `tests/test_accounts_env.py`,
  `tests/test_accounts_pools.py`, `tests/test_usage_account.py`,
  `tests/test_accounts_scheduler.py`, `tests/test_accounts_wiring.py`,
  `tests/test_accounts_transfer.py`, `tests/test_accounts_handoff_wiring.py`,
  `tests/test_accounts_single_account_equivalence.py`.
- **Implements:** D102–D111; full design in `doc/design/multi-account.md`.

### `audit.py`
- **Purpose:** capture and compare the security baseline: worktree `.git`
  pointer, resolved git config, `.agents/**`, instruction files, policy files
  and host-sensitive paths (`~/.ssh`, `~/.gnupg`, shell rc files,
  `~/.gitconfig`, `~/.netrc`, agy-mcp config, source repo `.git/config`).
- **Public API:**
  - `AuditSeverity` — `fatal` / `blocked` / `warn`.
  - `HostPathClass` — `strict` / `append_tolerant` / `warn_only`.
  - `classify_host_path()` — map a host path to its D52/D54 class.
  - `Finding` / `Findings` — one finding and its collection
    (`has_fatal`, `fatal_reason`, `blocked_files`, `passed`).
  - `AuditSnapshot` — serializable baseline for one job.
  - `save_snapshot()` / `load_snapshot()` — persist/load `snapshot.json`
    (load fails closed to `None` on oversize/corruption).
  - `take_host_path_snapshot()` — hash host paths (`mtime:size:sha256`).
  - `HostPathAuditResult` / `check_host_path_snapshot()` — classify changes;
    pure appends to `known_hosts` are benign, everything else is fatal.
  - `verify_host_path_snapshot()` — compatibility helper returning fatal paths.
  - `take_snapshot()` — build an `AuditSnapshot` for a job.
  - `audit()` — run all checks and return `Findings` (pure; no sleeps).
  - `run_security_audit()` — legacy tuple-returning compatibility helper.
- **Imports from `agy_mcp`:** `gitops.take_git_config_snapshot`,
  `gitops.diff_git_config_snapshots`, `models.Job`, `util.sha256_file`.
- **Called by:** `manager` (start/resume/review), `supervisor` (periodic,
  final, post-verify), `watcher` (pre-commit), `recovery` (post-crash).
- **Tests:** `test_audit.py`, `tests/audit/test_audit_baseline.py`, `tests/verify/test_verify_args.py`, `tests/supervisor/test_crash_recovery_stdout.py`,
  `tests/supervisor/test_bounded_reads.py`, `tests/supervisor/test_verify_tail_redaction.py`, `tests/server/test_path_leaks.py`, `test_policy_files.py`,
  `test_recovery.py`, `test_supervisor.py`, `tests/supervisor/test_watcher_commit_pipeline.py`,
  `tests/git/test_git_scenarios.py`.
- **Implements:** SPEC §12 (full), §16 (post-crash audit); D5, D41, D46, D52,
  D54, D56, D58.

### `cli_log.py`
- **Purpose:** read the head/tail of agy's `cli.log`, turn soft-denial lines
  into structured `Denial` records and resolve a strict conversation UUID from
  the two observed log lines.
- **Public API:**
  - `Denial` — step, tool, optional command/subagent id, raw line.
  - `read_cli_log_tail()` — bounded tail read (2 MB) with replacement decoding.
  - `read_cli_log_head()` — bounded head read (1 MB) for early lines.
  - `extract_conversation_id_from_cli_log()` — strict UUID from
    `Created conversation` / `resuming conversation`; returns `None` for the
    loose `Conversation using project ID` line (D81).
  - `extract_model_resolved()` — parse `model alias "<X>" resolved to "<Y>"`.
  - `extract_denials_from_cli_log()` — parse the two observed denial formats.
  - `format_denied_commands()` — cap to 20 entries / 500 bytes and wrap
    command text as untrusted.
- **Imports from `agy_mcp`:** `models.truncate_tail`,
  `models.wrap_untrusted_text`, `util.strict_uuid`.
- **Called by:** `parse_result` (re-export), `supervisor`, `recovery`.
- **Tests:** `test_cli_log.py`, `tests/server/test_untrusted_text.py`, `test_resume_and_commitmsg.py`.
- **Implements:** SPEC §15; D10, D50, D81.

### `cleanup_fixtures.py`
- **Purpose:** scan an agy-mcp state store, classify job records against a
  strict whitelist signature of throw-away pytest fixture rows, and with
  `--yes` safely remove confirmed candidate fixtures while writing an
  ids-only manifest.
- **Implementation:** the CLI lives in `cleanup/fixtures_cli.py` and the
  shared store primitives in `cleanup/store_io.py`; this top-level module is a
  re-export shim so `python -m agy_mcp.cleanup_fixtures` and the private names
  the tests import keep working.
- **Public API:**
  - `parse_args()` — CLI argument parser (`--store`, `--yes`, `--min-age-days`, `--json`).
  - `run_cleanup()` — execute dry-run scan or deletion returning structured report dict.
  - `main()` — CLI entrypoint returning exit code (0 success, 2 refusal, 1 unexpected error).
- **Imports from `agy_mcp`:** `cleanup.store_io` (shared primitives),
  `cleanup.fixtures_cli` (re-exported).
- **Called by:** `python -m agy_mcp.cleanup_fixtures` entrypoint.
- **Tests:** `tests/test_cleanup_fixtures.py`, `tests/test_cleaner_hardening.py`, `tests/test_cleaner_fixes.py`.
- **Implements:** SPEC §22; D87, D88.

### `cleanup_jobs.py`
- **Purpose:** scan an agy-mcp state store, list projects or classify job
  records by project repository path or explicit job IDs, and with `--yes`
  safely remove eligible stale job records while preserving git branches,
  repositories, worktrees, and conversation records.
- **Implementation:** `cleanup/jobs_cli.py` (classify → protect → report →
  delete), `cleanup/worktree_status.py` (registration decision),
  `cleanup/git_metadata.py` (strict git metadata readers) and
  `cleanup/store_io.py` (shared primitives); this top-level module is a
  re-export shim so `python -m agy_mcp.cleanup_jobs` keeps identical flags,
  output and exit codes.
- **Public API:**
  - `normalize_repo_path()` — deterministic tilde, parent, case and slash normalization.
  - `run_cleanup()` — execute dry-run scan or deletion returning structured report dict.
  - `parse_args()` — CLI argument parser (`--store`, `--list`, `--project`, `--job`, `--older-than-days`, `--yes`, `--json`).
  - `main()` — CLI entrypoint returning exit code (0 success, 1 partial deletion, 2 refusal or invalid arguments).
- **Imports from `agy_mcp`:** `cleanup.store_io`, `cleanup.git_metadata`,
  `cleanup.worktree_status`, `cleanup.jobs_cli` (all re-exported).
- **Called by:** `python -m agy_mcp.cleanup_jobs` entrypoint.
- **Tests:** `tests/test_cleanup_jobs.py`, `tests/test_cleanup_jobs_fixes.py`, `tests/test_cleanup_jobs_fixes2.py`, `tests/test_cleanup_jobs_fixes3.py`, `tests/test_cleanup_jobs_fixes4.py`, `tests/test_cleanup_jobs_fixes5.py`.
- **Implements:** SPEC §23; D89, D90, D91, D92, D93, D94.

### `config.py`
- **Purpose:** define the config dataclass, validate TOML types/ranges/regexes,
  and load `~/.config/agy-mcp/config.toml` with fail-closed errors.
- **Public API:**
  - `ConfigError` — invalid syntax/type/value (subclass of `ValueError`).
  - `Config` — all documented config keys plus `unknown_keys`.
  - `load_config()` — resolve path, parse TOML, validate, merge defaults.
- **Imports from `agy_mcp`:** none.
- **Called by:** `server.setup_server`; the resulting `Config` is passed to
  `JobManager` and `worktree` functions.
- **Tests:** `test_config.py` (direct), plus ~29 integration suites that build
  a `Config` (direct-import count from `grep`).
- **Implements:** SPEC §18; D56, D57, D59.

### `gitops.py`
- **Purpose:** every git interaction and the commit pipeline: hardened `git`
  execution, `index.lock` retry, porcelain parsing, junk/sensitive filtering,
  staging, commit, checkpoint/safety-net commits, merge-base/ahead-behind,
  diff stats/commits and git-config snapshots.
- **Public API:**
  - `GitError` — non-zero git exit with `returncode`, `stderr`, `stdout`,
    `cmd_args`.
  - `GitResult`, `StagingResult`, `SkippedFile` — result records.
