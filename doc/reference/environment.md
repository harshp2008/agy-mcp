# Environment variables

Status: current
Audience: operators, contributors

Sixteen variables are read by the server or the installer: four by
`src/agy_mcp/` and twelve by `installer/install.sh`. The first table is generated
from those reads. The second table is the hand-written effect and default; when
a new `os.environ` read or `AGY_MCP_*` installer input appears, the generated
table changes and `scripts/check_docs.py` fails until this page is refreshed.

## Effect and default

| Variable | Effect | Default when unset |
|---|---|---|
| `HOME` | The parent home directory: `Path.home()` supplies the default state/config roots, the cleaners refuse a store outside `HOME`, and the child environment receives `HOME` so `agy` and git operate on the same home. | The process's real home from the OS. |
| `PATH` | `shutil.which("agy")` resolves the default binary; the sanitized child environment passes `PATH` through (or the fallback below). | `/usr/local/bin:/usr/bin:/bin` for the child; the parent's `PATH` for `which`. |
| `XDG_CONFIG_HOME` | Config directory when `--config` is absent: `$XDG_CONFIG_HOME/agy-mcp/config.toml`. | `~/.config/agy-mcp/config.toml`. |
| `XDG_STATE_HOME` | State root when `--state-dir` is absent: `$XDG_STATE_HOME/agy-mcp`. | `~/.local/state/agy-mcp`. |
| `AGY_MCP_CLIENT` | Installer target: `dsh` or `generic`. | `generic` (no dsh files are written). |
| `AGY_MCP_DRY_RUN` | `1` prints every file and command and changes nothing. | off. |
| `AGY_MCP_SRC` | Source tree or archive to install from. | The repository containing the installer (`installer/..`). |
| `AGY_MCP_EDITABLE` | `1` forces an editable (`pip install -e`) install. | off; an editable install already live is left in place. |
| `AGY_MCP_UPGRADE` | `1` reinstalls from `AGY_MCP_SRC` even when the venv already imports `agy_mcp`. | off. |
| `AGY_MCP_PYTHON` | Interpreter used to create the venv and run pip; must be Python 3.12 or newer. | `python3`. |
| `AGY_MCP_PIP_ARGS` | Extra pip arguments, split on whitespace (for example `--no-index`). | empty. |
| `AGY_MCP_NO_RESTART` | `1` skips the dsh restart after registration. | off. |
| `AGY_MCP_AGY_BINARY` | `agy` executable to use; must exist and be executable. | `agy` on `PATH`, then `~/.local/bin/agy`. |
| `AGY_MCP_CONFIG_PATH` | Config path override written into `run.sh`. | `$XDG_CONFIG_HOME/agy-mcp/config.toml`, else `~/.config/agy-mcp/config.toml`. |
| `AGY_MCP_STATE_DIR` | State directory override written into `run.sh`; the test bootstrap also sets it. | `$XDG_STATE_HOME/agy-mcp`, else `~/.local/state/agy-mcp`. |
| `AGY_MCP_ALLOW_INSIDE_DSH` | `1` bypasses the installer's refusal to change dsh registration from inside a dsh session. Use only when dsh will not be restarted. | off (the installer refuses). |

## Not input variables

- `AGY_MCP_CONFIG` and `AGY_MCP_REPO_DEFAULT` are generated by the installer
  (written into `run.sh` / derived from the script path). They are not inputs.
- `CONF_DIR` selects the installer's config directory (`$HOME/.config/ai-stack`
  by default); `DSH_PROFILE_DIR`, `DSH_AGENTS_PATH`, `DSH_SESSION_ID`,
  `DSH_HOME` and `DSH_PROFILE` are consulted for dsh registration and the
  inside-dsh refusal. They are outside the sixteen-variable operator table.
- Test-only variables (`FAKE_AGY_SCENARIO`, `FAKE_AGY_RECORD`,
  `FAKE_AGY_CLI_LOG_MODE`, `FAKE_AGY_IGNORE_CONVERSATION`,
  `FAKE_AGY_FRESH_UUID_SEED`, `FAKE_AGY_HOME`, `AGY_HOME`) are documented in
  `tests/fake_agy/README.md`.
- The child environment is built from scratch by `util.env_allowlist`; it is
  **not** a copy of the parent. It contains `HOME`, `PATH`, `LANG=C.UTF-8`,
  `TMPDIR=<job>/tmp`, `GIT_CONFIG_COUNT` and the `GIT_CONFIG_KEY_n`/
  `GIT_CONFIG_VALUE_n` override pairs (`core.fsmonitor=false`,
  `core.hooksPath=/dev/null` unless the wrapper-owned commit path honours hooks,
  `core.pager=cat`). Verification runs add `PYTHONDONTWRITEBYTECODE=1` and
  `PYTEST_ADDOPTS=-p no:cacheprovider`.

## Sources

- `src/agy_mcp/jobs.py` — `XDG_STATE_HOME` and the state-root default.
- `src/agy_mcp/config.py` — `XDG_CONFIG_HOME` and the config path.
- `src/agy_mcp/util.py` — `PATH` and the sanitized child environment.
- `src/agy_mcp/cleanup/jobs_cli.py`, `src/agy_mcp/cleanup/fixtures_cli.py` — the `HOME`

  inside-dsh refusal and the dsh-related variables.

  and `AGY_MCP_STATE_DIR`.
